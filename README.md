# PartnerHub — Taxi & Driver Partnership Website

Responsive multilingual website for a taxi partnership service in Poland.

PartnerHub presents services for drivers, couriers, and vehicle fleet owners, including cooperation, employment, vehicle services, and contact options.

## Live Demo

The site is designed to be deployed with GitHub Pages.

## Features

- Responsive layout for desktop and mobile devices
- Multilingual interface with saved language selection via `localStorage`
- Responsive navigation and dropdown menus
- Modal windows and smooth scrolling
- Animated hero and page elements
- Direct Telegram, phone, and email contact links
- Service and partnership presentation sections

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM API and `localStorage`
- CSS animations
- Google Fonts
- Responsive Web Design

## Getting Started

No build tools or backend are required.

1. Clone the repository.
2. Open the project directory.
3. Open `index.html` in a browser, or serve the folder with any static web server.

## Implementation Highlights

The interface updates its multilingual content dynamically through `data-translate` attributes. The chosen language is stored in the browser so it remains selected on the next visit. JavaScript also manages navigation interactions, dropdowns, modal windows, scrolling, header state, and animations.
